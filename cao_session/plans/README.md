# plans/ — session reports & local plans

Working notes that belong to *you*, not the repo: per-session reports, plans,
scratch, design drafts. Everything here except this README is gitignored
(`plans/*` with `!plans/README.md`), so you can keep dated files
(`19sep.md`, `session-notes.md`, …) without them landing in git.

Use it for:
- **Session reports** — what a work session did, decisions, follow-ups.
- **Plans** — multi-step plans before they turn into code.
- **Scratch** — anything transient.

Durable, shareable design docs that SHOULD be versioned go in the repo proper
(a tracked `docs/`), not here. The `cao_session/` folder (task boards, diagrams
the supervisor writes per run) is separately gitignored too.
