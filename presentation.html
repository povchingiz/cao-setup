The Challenge

The 5 Fatal Flaws of Single-Agent Coding

Why lone coding agents hit walls on real production repositories.

🪟
Siloed Terminals
Claude Code, Codex, Agy, and OpenCode each operate in isolated terminal bubbles with no shared contracts, task queues, or coordination.
💸
Token & Quota Burn
Spending frontier reasoning models (Claude Opus/Sonnet) on mundane CRUD, boilerplate typing, or reading huge repos burns rate limits in minutes.
📉
Context Rot & Amnesia
Long-running sessions accumulate thousands of lines of raw tool outputs. Context saturates, leading to hallucinations and forgotten past fixes.
💥
Multi-Agent Collisions
Running multiple autonomous agents concurrently on the same codebase causes catastrophic race conditions and conflicting file overwrites.
🛑
Premature "Done" Claims
Standard agents declare victory the instant code is typed—without running AST checks, security audits, or verifying test regressions.
⚡
Mid-Run Quota Freezes
Hitting an unexpected HTTP 429 quota ceiling in the middle of a complex multi-file refactor completely halts the development process.
Core Solution

Route every coding task to the engine that is best (and most economical) at that specific job.

Intelligence Layer

Hermes Continuous Learning System

Zero API cost, sub-millisecond retrieval, and persistent cross-session memory.

1. Episodic Memory (SQLite FTS5)

Full-text indexed search with BM25 ranking. Stores past solutions, compiler fixes, and architectural choices across all runs.

# CLI: Query memory anytime
cao-memory recall "sqlite3 OperationalError"
# Dispatched workers inherit past lessons automatically!
2. Hermes 50% Compaction Rule

Tracks turns and estimated tokens during execution. When conversation history reaches 50% of the active window, it automatically compresses verbose tool outputs into structured checkpoints in now.md.

ContextCompactor.record_turn()
if compactor.should_compact():
    compact_history_to_now_md()
3. Retrospective Storage & Procedural Skills

Whenever the self-healing loop resolves a failure, the root cause and resolution are automatically indexed into wcao/memory.sqlite and written as reusable Markdown recipes in wcao/skills/. Future workers never repeat the same mistake.

Quota Intelligence

TokenMaster: Proactive Quota Awareness

Sensing rate-limit ceilings and preventing 429 errors before they happen.

Telemetry Sensing
Live Window Monitoring
Reads Claude's on-disk rate-limit event stream (5-hour and 7-day windows) and reset timestamps without making external API calls.
Claude 7-day: 89% util → NEAR LIMIT
Watermark Swapping
80% Safety Watermark
When quota utilization reaches ≥ 80%, TokenMaster proactively reassigns tasks from claude_worker to hermes_worker or coder_worker before dispatch.
Swapped: True (Util 89% ≥ 80%)
Cooling-Off Cache
Cross-Engine Protection
If Codex or AGY hits a server-side 429, TokenMaster marks the engine blocked for 1 hour. All remaining DAG tasks swap proactively without failing.
mark_engine_blocked("codex")
Autonomous Execution

Headless DAG Scheduler (cao_auto)

Safe, parallel, conflict-free multi-agent task execution.

DAG Dependencies (depends_on)

Evaluates topological dependencies so downstream implementation steps never begin until prerequisites are verified and marked done.

Task 01 (Arch) → Task 02 (Impl) → Task 03 (Tests)
File Disjointness Locks (files)

If Worker A is editing run/cao_auto.py, no other worker touching that file can run concurrently. Guarantees zero merge conflicts and zero overwritten edits.

Worker 1 locks: ["run/cao_auto.py"]
Worker 2 locks: ["tests/test_auto.py"] → PARALLEL OK
Quality Assurance

Self-Healing & Anti-Tampering Gates

Ensuring code is verified, honest, and resilient against regressions.

Aggressive Audit Gate
cao-aggressive
Automated AST compilation across all Python files, shell syntax verification, hardcoded secrets scans, and complete test suite execution.
Anti-Test-Tampering
cao_tamper.py
Detects if workers weaken assertions, delete test functions, or insert assert True to cheat the audit. Automatically reverts test edits!
Architect Escalation
Level 2 Escalation
If a bulk coder fails to fix an audit issue on attempt 1, attempt 2+ escalates to hermes_worker or claude_worker for architectural root-cause diagnosis.
