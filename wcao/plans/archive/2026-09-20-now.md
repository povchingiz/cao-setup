# NOW — cao-setup progress snapshot

Working session state so context can be freed. This file is local scratch.

## What this is
`cao-setup` = provisioner + config layer for a CLI Agent Orchestrator (CAO).
`cao-run` launches a Claude **supervisor** that delegates to four workers.

- Local repo: `~/cao-setup`
- Remote: `git@github.com:povchingiz/cao-setup.git` (private, in sync)
- Live CAO state: `~/.aws/cli-agent-orchestrator/` + `~/.config/cao/` + `~/.aws/opencode/`
- Launcher: `~/.local/bin/cao-run`, `~/.local/bin/cao-doctor`
- cao-server daemon: background, owns tmux worker sessions

## Workers (all verified end-to-end earlier)
| worker | engine | role |
|--------|--------|------|
| claude_worker | claude_code | architecture, contracts, hard logic |
| opencode_worker | opencode + cheap model (local: nitec/DeepSeek-V4-Pro) | bulk: schemas, CRUD, boilerplate |
| codex_worker | codex (ChatGPT) | frontend / UI |
| antigravity_worker | agy (Gemini) | structured audit: style/security/tests/perf |

## Daily loop
- Edit `2_configure/cao.config.toml` (or a prompt) → `./3_apply/apply.sh`
- Launch: `cao-run` (runs cao-doctor gate first)
- Reattach: `tmux attach -t cao-supervisor`; detach `Ctrl-b d` (workers keep running)
